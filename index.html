  • デモ銀行（学習用ネットバンキング）

    入金・振込・承認・取消といった金融システムの業務の流れを体験できるデモです。操作するたびに「チェック → 更新 → 記録」の処理ステップと、変更されたデータの行を画面上に表示します。承認権限・ダブルチェック・障害時の不整合と残高照合など、業務システムで大事になる部分を再現しました。

    デモ用ログイン：ID demo / パスワード password
    データはお使いのブラウザ内にのみ保存され、画面下部の「データ初期化」でいつでも元に戻せます。

  • 用件（予定の打診アプリ）

    要件と日にちだけを送り、返事は「はい / いいえ」だけで答える、スマホ向けのやりとりアプリです。返事を変えるときだけ一言（50文字まで）の理由が必要になる仕組みで、気軽さと「ドタキャンしにくさ」の両立を狙いました。

    ご利用には Google アカウントでのログインが必要です。
    使用技術：React (Vite) / TypeScript / Firebase（Hosting / Firestore / Authentication / Cloud Functions）
