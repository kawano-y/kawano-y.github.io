# kawano-y.github.io

ITエンジニアとしての自分用ホームページ。GitHub Pages で https://kawano-y.github.io に公開している。
直接案件の獲得にも使う予定。

## 構成

- `index.html` 1枚のシンプルな構成。CSS も同じファイルの `<style>` に書く。
- ビルドツールやフレームワークは入れない（main に push すればそのまま公開される）。
- セクション：About / Skills / Works / Contact

## 守ること

- このリポジトリは公開されている。AWS のアカウントID・アプリID・本物の秘密情報は書かない。
- 全拒否の `robots.txt` や `noindex` は置かない。ホームページは検索で見つけてもらいたい。
  （デモアプリ側は逆にインデックスさせない設定にしてある）
- 個人情報は名前までにする。住所・電話番号・顔写真は載せない。
- メールアドレスはサイトに直接載せない。問い合わせはフォーム経由にする。
- Works に載せるデモのログイン情報は、デモ専用のもの（他で使っていないもの）に限る。
- 日本語は HTML 内で改行すると表示上に空白が入るため、段落は1行で書く。

## 進め方

- 返答は日本語で。
- HTML/CSS を変更するときは、なぜそう書いたかを軽く添える（HTML/CSS は不慣れなため）。
- 見た目を変えたら、パソコン幅とスマホ幅（375px 前後）の両方で崩れていないか確認する。
